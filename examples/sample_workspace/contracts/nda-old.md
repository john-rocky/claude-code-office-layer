# 秘密保持契約 (NDA) — Version 1.0

本契約は **ACME 株式会社** (以下「甲」) と **ジョン・ロッキー** (以下「乙」) との間で、下記のとおり締結する。

## 第1条 (定義)
本契約において「秘密情報」とは、本契約の履行に関連して開示されるすべての情報をいう。

## 第2条 (秘密保持義務)
受領者は秘密情報を **3年間** 第三者に開示してはならない。

## 第3条 (損害賠償)
本契約違反により生じた損害については、 **上限なし** で賠償の責任を負う。

## 第4条 (準拠法)
本契約は日本法に準拠する。

## 第5条 (合意管轄)
東京地方裁判所を専属的合意管轄とする。
